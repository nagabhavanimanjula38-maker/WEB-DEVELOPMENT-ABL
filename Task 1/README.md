# Task-1: Digital Library Management Website

## Project Description
The Digital Library Management Website is a web-based interface designed to display books, their authors, categories and availability status. It helps users explore different book categories and view library information through a simple and user-friendly design.

## Objectives
- To design an attractive digital library webpage.
- To display different book categories and author details.
- To show book availability information.
- To provide search and filter interface elements.
- To present library rules and contact information.

## Features
- Attractive homepage with navigation menu.
- Book categories displayed using responsive cards.
- Book catalog with book names, authors, categories and availability.
- Search bar and category and availability filter interface elements.
- Library rules section.
- Contact information section.
- Responsive layout for different screen sizes.

## Technologies Used
- HTML5 – For webpage structure and content.
- CSS3 – For styling, layouts, colors, hover effects and responsiveness.

## How to Run
1. Download or clone this repository.
2. Open the `Task-1-Digital-Library` folder.
3. Open `index.html` in a web browser.
4. Explore the different sections of the website.

## Note
The search and filter elements are currently interface designs. Actual searching and filtering functionality requires JavaScript or backend implementation.

## Conclusion
This project demonstrates how HTML and CSS can be used to develop a professional digital library interface with organized book information and responsive layouts.
