# Task-3: Travel Agency Website – Wanderway Travel

## Project Description
Wanderway Travel is a travel agency website designed to help users explore popular destinations, view holiday packages and understand available transportation options. It provides travel information, sample package details, itineraries and a travel enquiry form through a user-friendly interface.

## Objectives
- To develop an attractive travel agency webpage.
- To display popular travel destinations.
- To provide holiday package details, prices and durations.
- To present sample travel itineraries.
- To display available transportation options.
- To create a travel enquiry form.

## Features
- Attractive homepage with a travel banner.
- About the travel agency section.
- Popular destinations displayed using image cards.
- Holiday packages with prices and durations.
- Sample travel itinerary.
- Train and bus transportation information.
- Travel enquiry form with HTML validation attributes.
- Contact information section.
- Responsive layout for different screen sizes.

## Popular Destinations
- Goa
- Kerala
- Hyderabad

## Technologies Used
- HTML5 – For webpage structure, content, forms and tables.
- CSS3 – For styling, responsive layouts, image cards, hover effects and design.

## How to Run
1. Download or clone this repository.
2. Open the `Task-3-Travel-Agency` folder.
3. Open `index.html` in a web browser.
4. Explore destinations, packages, itineraries and enquiry details.

## Note
The destination packages and prices are sample information for this academic project. The enquiry form is a frontend demonstration. Actual enquiry submission and travel booking require a backend or connected form service.

## Conclusion
This project demonstrates how HTML and CSS can be used to create a professional travel agency website with destination information, holiday packages, itineraries and an enquiry interface.
