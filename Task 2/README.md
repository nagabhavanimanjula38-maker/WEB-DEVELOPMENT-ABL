# Task-2: College Fest Management Website – Freshers Day 2026

## Project Description
The College Fest Management Website is designed to provide information about a college event in an organized and attractive way. This project presents Freshers Day 2026 at Dr. RVR NRI Deemed to be University and provides details about event activities, schedules, rules and student registration.

## Event Details
- **College Name:** Dr. RVR NRI Deemed to be University
- **Event Name:** Freshers Day 2026
- **Date:** 8th November 2026
- **Starting Time:** 10:00 AM

## Objectives
- To create an attractive college event webpage.
- To display event information and highlights.
- To present the event schedule.
- To provide rules and guidelines for participants.
- To design a student registration form.

## Event Activities
- Dancing
- Singing
- Skit
- Other Extracurricular Activities

## Features
- Attractive Freshers Day event banner.
- Navigation menu for easy access to website sections.
- About the event section.
- Event highlights displayed using responsive cards.
- Event schedule displayed using a structured table.
- Rules and guidelines section.
- Student registration form with HTML validation attributes.
- Contact information section.
- Responsive design for different screen sizes.

## Technologies Used
- HTML5 – For webpage structure, content and registration form.
- CSS3 – For styling, colors, layouts, hover effects and responsiveness.

## How to Run
1. Download or clone this repository.
2. Open the `Task-2-College-Fest` folder.
3. Open `index.html` in a web browser.
4. Navigate through the sections to explore the event details.

## Note
The registration form demonstrates HTML form fields and browser-side validation. Actual registration data storage requires a backend or connected form service.

## Conclusion
This project demonstrates how HTML and CSS can be used to develop a professional college event website that presents event details, activities, schedules and registration information in an organized manner.
